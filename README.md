# task-management-dashboard
Personal project task management dashboard
Core features:
	•	Register / Login
	•	Protected routes
	•	Dashboard overview
	•	Task CRUD
	•	Search / Filter / Sort
	•	Summary cards
	•	Recent tasks
	•	Responsive layout


Phase 1: 项目初始化
	•	前端 Vite + React + Tailwind
	•	后端 Express
	•	PostgreSQL 连接
	•	配置 cors / dotenv / nodemon

Phase 2: 用户系统
	•	注册
	•	登录
	•	JWT token
	•	受保护路由

Phase 3: 任务 CRUD
	•	创建任务
	•	任务列表
	•	编辑任务
	•	删除任务

Phase 4: dashboard 页面
	•	summary cards
	•	统计数据
	•	最近任务
	•	图表

Phase 5: 体验优化
	•	loading
	•	error handling
	•	empty state
	•	responsive
	•	form validation
	•	search/filter/sort/pagination

Phase 6: 部署
	•	前端部署 Vercel / Netlify
	•	后端部署 Render / Railway
	•	PostgreSQL 云数据库
